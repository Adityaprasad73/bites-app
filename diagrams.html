🍽️ Bites App

Technology stack & architecture overview

Diagram 1 — Tech Stack

⚛️
React 18
Frontend Framework
Builds every page — home, restaurant menu, order tracking, delivery dashboard. Uses hooks, context, and lazy loading.
UI Layer
⚡
Vite
Build Tool
Instantly compiles and hot-reloads React code during development. Bundles the app for production on Vercel.
Dev Tools
🎨
Tailwind CSS
Styling
All styling is written as utility classes directly in JSX. Handles dark mode, responsive layout, and custom design tokens.
UI Layer
🟩
Node.js + Express
Backend Server
Handles all HTTP requests — user auth, placing orders, updating statuses, restaurant menus. Runs on Railway 24/7.
API Layer
🍃
MongoDB + Mongoose
Database
Stores users, restaurants, menu items, orders, and reviews. Mongoose provides typed schemas and easy querying.
Data Layer
🔌
Socket.io
Real-time
Powers live order status updates and GPS tracking. Partner broadcasts location → server relays → customer sees pin move on map.
Real-time
🗺️
Leaflet + OpenStreetMap
Maps
Shows the delivery route and live partner pin on the order tracking page. Free — no API key or credit card needed.
Maps
🔐
JWT Auth
Authentication
After login the server issues a signed token stored in localStorage. Every protected request sends it in the Authorization header.
Security
🌐
React Router v6
Routing
Handles client-side navigation between pages (home, restaurant, cart, track order, dashboard) without page reloads.
Navigation
▲
Vercel
Frontend Hosting
Deploys the React app globally on a CDN. Auto-deploys whenever you push to GitHub master branch.
Deployment
🚂
Railway
Backend Hosting
Runs the Node.js server and MongoDB. Keeps the server alive 24/7 with persistent storage and environment variables.
Deployment
📦
Context API
State Management
AuthContext holds the logged-in user. CartContext holds cart items in memory and syncs to localStorage (versioned to avoid stale IDs).
State

  • join:order room
  • join:user room
  • join:delivery_pool
  • partner:location emit
  • order:update receive
HTTPS REST + WebSocket (wss://)
Server — Railway (Node.js / Express)
🔐 Auth Routes
  • POST /register
  • POST /login → JWT
  • PATCH /toggle-online
  • PATCH /profile
  • JWT middleware
🍽️ Restaurant Routes
  • GET /restaurants
  • GET /:id/menu
  • GET /:id/reviews
  • POST /restaurants
  • PUT /:id/menu items
📦 Order Routes
  • POST /orders (place)
  • GET /orders/:id
  • PATCH /:id/status
  • POST /:id/rate
  • GET /delivery/feed
  • GET /delivery/history
🔌 Socket.io Server
  • Room: order:{"{id}"}
  • Room: user:{"{id}"}
  • Room: restaurant:{"{id}"}
  • Room: delivery_pool
  • Relay partner:location
  • Broadcast order:update
Mongoose ODM
Data — MongoDB Atlas
👤 Users
  • name, email, phone
  • role (customer/partner/restaurant)
  • isOnline, vehicleType
  • bcrypt hashed password
🏪 Restaurants
  • name, address, image
  • cuisine, rating
  • owner (ref: User)
  • menu items array
📋 Orders
  • items, total, address
  • status + statusHistory
  • customer, restaurant (refs)
  • deliveryPartner (ref)
  • customerRating, review
tile requests (no API key)
External Service
🗺️ OpenStreetMap
  • Serves map tile images
  • Free, no API key
  • Leaflet fetches tiles directly
